## 🆔 The Identity Reset Build

For the case where the ban followed the machine, not the account.

| **Identifier** | **What happens to it** |
| --- | --- |
| Volume serial number | regenerated |
| Physical disk serial | masked |
| Network adapter MAC | regenerated |
| SMBIOS / board UUID | rebuilt |
| Windows Machine GUID | replaced |
| GPU device identifiers | masked |
| Stored ban markers | cleared |

**Sequence is not optional**

1. Exit the game **and** its launcher completely — check the tray.
2. Run the loader as administrator.
3. Open the identity tab and apply.
4. **Restart Windows.** Half of these values are read during boot; without the
   restart the old identifiers come straight back.
5. Create the new account only after the reboot.

Skipping the restart is the single most common reason people report that the reset
"did nothing".

**What it cannot do**

It does not restore a banned account, and it does not change anything about an
account-level ban. Its purpose is to make the machine look like a different
machine, so a new account is not automatically associated with the old one.

**Verify before you commit**

After the reboot, confirm the values actually changed before logging into anything.
Half-applied resets are worse than none, because you burn the new account on an
identity that is still linked.

**Rest of the pack**

The overlay, aim assistance and the config system are included and behave exactly
as they do in the other builds.
